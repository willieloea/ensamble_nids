\section{Methodology and Implementation}
\label{sec:methodology}

Data preparation and algorithmic implementations developed for the study are described in Section~\ref{sec:methodology}. Subsection~\ref{subsec:meth_data} details the preprocessing of the intrusion detection dataset and the representation of descriptive attributes. Subsection~\ref{subsec:meth_tree} explains the extended decision-tree learner and the incremental numerical threshold scorer. Subsection~\ref{subsec:meth_pruning} describes the bottom-up reduced-error pruning implementation. Subsection~\ref{subsec:meth_ensemble} presents the generic bagging and multiclass boosting frameworks. Finally, Subsection~\ref{subsec:meth_balance} formulates the hybrid class-balanced resampling policy.

\subsection{Dataset Preprocessing and Feature Representation}
\label{subsec:meth_data}
The empirical study used a subset of the UNSW-NB15 dataset~\cite{Moustafa2015} containing $n = 257{,}673$ network flow records. The target attribute \texttt{attack\_cat} assigned each record to one of $k = 10$ traffic categories: \emph{Normal}, \emph{Reconnaissance}, \emph{Backdoor}, \emph{DoS}, \emph{Exploits}, \emph{Analysis}, \emph{Fuzzers}, \emph{Worms}, \emph{Shellcode}, and \emph{Generic}, indexed by $j \in \{1, \dots, 10\}$ corresponding to integer codes zero through nine.

Exploratory data analysis guided four preprocessing steps prior to model induction:
\begin{enumerate}
    \item \textbf{Removal of non-predictive and duplicate attributes:} The record identifier \texttt{id} was removed so that decision trees did not split on row indices. The binary attribute \texttt{is\_ftp\_login} was also removed because exploratory analysis showed that \texttt{is\_ftp\_login} duplicated the file transfer protocol (FTP) command counter \texttt{ct\_ftp\_cmd}.
    \item \textbf{Encoding of informative missingness in \texttt{service}:} Missing values occurred only in the application-layer \texttt{service} attribute, and the rate of missingness varied substantially across attack categories. Specifically, \texttt{service} was missing in $100.0\%$ of \emph{Shellcode} records, $95.28\%$ of \emph{Backdoor} records, and $90.65\%$ of \emph{Fuzzers} records, compared with $1.55\%$ of \emph{Generic} records and $14.94\%$ of \emph{Worms} records. To retain the predictive signal associated with unidentified application services, missing entries in \texttt{service} were replaced with the explicit category string \texttt{'other'}.
    \item \textbf{Separation of categorical and ordered numerical attributes:} After cleaning, $m = 41$ descriptive attributes remained. Four attributes were represented as discrete categorical predictors: transport protocol \texttt{proto} with 133 distinct levels in the growth pool, application service \texttt{service}, connection state \texttt{state}, and the binary address-port indicator \texttt{is\_sm\_ips\_ports}. The remaining 37 attributes, comprising flow durations, packet inter-arrival times, bitrates, transmission control protocol (TCP) round-trip times, and integer packet, byte, and connection counters, were represented as ordered numerical predictors tested via binary threshold splits. Because decision trees test categorical levels directly and partition numerical attributes by order-preserving thresholds, neither numerical feature scaling nor one-hot encoding was applied.
    \item \textbf{Retention of correlated predictors and repeated flow vectors:} Pairwise correlation screening across the numerical predictors in the growth pool identified 20 attribute pairs satisfying $\max(|\mu|, |\rho|) \ge 0.95$, where $\mu$ denotes the Pearson linear correlation coefficient and $\rho$ denotes the Spearman rank correlation coefficient. Strong examples included \texttt{sbytes} and \texttt{sloss} with $\mu = 0.9958$, and \texttt{tcprtt} and \texttt{synack} with $\rho = 0.9963$. In greedy tree induction, two globally correlated counters provide distinct local split thresholds, and anomalous traffic often manifests on records where coupled network counters diverge. A preliminary complete-link correlation ablation on 2,000 fitting rows reduced the 41 predictors to 27 under two target-independent representative policies, lowering mean validation macro-averaged F1-score by $0.0151$ and $0.0030$ for unpruned trees and by $0.0218$ and $0.0078$ for pruned trees. Consequently, all 41 cleaned predictors were retained. Repeated identical 41-attribute vectors were likewise retained during preprocessing because flow multiplicity reflects natural traffic frequencies that inform both node entropy calculations and majority-class selection during reduced-error pruning.
\end{enumerate}

\subsection{Extended Decision Tree Implementation}
\label{subsec:meth_tree}
All decision-tree models were implemented in Python using \texttt{pandas} data frames with the target attribute placed in the final column. The base learner extended the categorical ID3 algorithm~\cite{Quinlan1986} to support continuous threshold splits, configurable impurity functions, optional maximum depth pre-pruning at depth $d$, and model persistence to disk via the \texttt{pickle} module.

\subsubsection{Tree Structure and Unseen-Category Fallbacks}
Induced decision trees were represented as nested Python dictionaries where terminal leaves stored scalar class labels. A categorical internal node mapped the selected attribute name to a dictionary of child subtrees keyed by each domain level $l \in L_b$. A numerical internal node mapped a two-element tuple of the attribute name and threshold $\theta$ to a dictionary containing the left branch for $x_{i,b} < \theta$ and the right branch for $x_{i,b} \ge \theta$. A categorical attribute selected at an internal node was removed from the candidate set along descendant branches, whereas a numerical attribute remained available for subsequent threshold splits deeper in the tree.

When trees were trained on small subsamples or resampled replicates, rare categorical levels present in the broader growth pool were absent from individual local training partitions. To ensure that every known category had a valid branch during pruning and evaluation, the learner accepted a domain dictionary mapping each categorical attribute $b$ to the complete level set $L_b$ observed in the growth pool. Any level $l \in L_b$ receiving zero instances at an internal node was assigned a leaf predicting the modal target class of that node. If an evaluation record contained a categorical value absent from the entire growth-pool domain $L_b$, the experiment prediction wrapper returned the global modal training class of the fitted model.

\subsubsection{Incremental Numerical Threshold Scoring}
Evaluating candidate numerical thresholds by constructing a new boolean mask and rescanning the data frame for every midpoint $\theta$ becomes computationally prohibitive when $n > 10^5$ across 37 numerical attributes. To make full-pool induction and ensemble training tractable, an incremental single-sort threshold scorer was implemented that produced exact mathematical equivalence to exhaustive partition scoring while reducing per-attribute complexity from $u \cdot n$ scans to $n \log_2 n + u k \log_2 k$ operations for $n$ instances, $u$ distinct attribute values, and $k$ classes:
\begin{enumerate}
    \item The node partition $D$ was sorted once by the candidate numerical attribute $b$ using a stable sort, and target labels were mapped to integer codes.
    \item Identical values of attribute $b$ were grouped into ordered pairs $(v_1, \mathbf{c}_1), \dots, (v_u, \mathbf{c}_u)$, where $v_\tau$ for $\tau \in \{1, \dots, u\}$ denotes the $\tau$-th distinct value and $\mathbf{c}_\tau$ denotes the $k$-element class-count vector at value $v_\tau$. Grouping equal values prior to threshold generation ensured that identical attribute values were never split across branches.
    \item A right-branch class-count vector $\mathbf{c}_2$ was initialised to the total node class distribution and a left-branch class-count vector $\mathbf{c}_1$ was initialised to the zero vector. Scanning sequentially across adjacent value groups $\tau$ and $\tau + 1$, the scorer transferred $\mathbf{c}_\tau$ from $\mathbf{c}_2$ to $\mathbf{c}_1$ in $k$ arithmetic operations.
    \item Whenever two adjacent groups $\tau$ and $\tau + 1$ were both homogeneous and shared the same class label, the boundary between $v_\tau$ and $v_{\tau+1}$ did not improve impurity and was skipped~\cite{Kelleher2020}. For all other adjacent pairs, the midpoint $\theta_\tau = v_\tau / 2 + v_{\tau+1} / 2$ was scored directly from the updated count vectors $\mathbf{c}_1$ and $\mathbf{c}_2$.
\end{enumerate}

\subsection{Bottom-Up Reduced-Error Post-Pruning}
\label{subsec:meth_pruning}
Given an induced tree, the fitting dataset $D_f$, and a disjoint pruning dataset $P$, the reduced-error pruning routine returned a pruned copy without mutating the original unpruned tree. Consequently, each unpruned tree and the corresponding pruned tree shared the exact same initial fit.

The pruning algorithm traversed the tree in post-order, visiting all child subtrees before their parent node while routing the corresponding subsets $D_v \subseteq D_f$ and $P_v \subseteq P$ to each internal node $v$:
\begin{itemize}
    \item At internal node $v$, the modal class $y^*_v$ of the reaching fitting instances $D_v$ was determined, resolving ties by the first modal value in series order. If $D_v$ was empty, the subtree at $v$ was left unchanged and scored once on $P_v$.
    \item Each recursively pruned child of $v$ returned both the pruned child subtree structure and the integer count of unweighted classification errors committed on the routed child subset of $P_v$. Summing the child error counts yielded the retained subtree error count $e_v$ without re-predicting descendant paths.
    \item The error count $o_v$ of replacing the subtree at $v$ with a single leaf predicting $y^*_v$ was computed on the reaching pruning subset $P_v$ as
    \begin{equation}
        o_v = \sum_{(\mathbf{x}_i, y_i) \in P_v} \delta(y_i \ne y^*_v).
        \label{eq:leaf_err}
    \end{equation}
    \item If $o_v \le e_v$, the subtree at $v$ was replaced by the leaf $y^*_v$ and returned $o_v$ to the parent node; otherwise, the pruned subtree was retained and returned $e_v$.
\end{itemize}
Because equality between $o_v$ and $e_v$ favoured replacement, any internal node reached by zero pruning observations was collapsed into the leaf $y^*_v$.

\subsection{Ensemble Frameworks}
\label{subsec:meth_ensemble}
The ensemble module used a generic callback interface where each ensemble constructor accepted a model-training function and a single-row prediction function, returning a serialisable voting ensemble object.

\subsubsection{Bagging and Sub-Bagging}
For an ensemble of $t$ base learners, standard bagging drew $n$ instances with replacement per member $r \in \{1, \dots, t\}$, whereas sub-bagging drew $\omega < n$ instances without replacement. Each base tree received a unit voting weight $\alpha_r = 1.0$. At inference time, hard predictions were combined via Equation~(\ref{eq:bagging_vote}), with voting ties broken deterministically by the order of first appearance of class labels in the training set. When evaluating ensemble prefixes across size checkpoints $t \in \{5, 10, 25, 35, 50\}$, member predictions on fixed evaluation partitions were cached so that each checkpoint evaluated only the newly added base trees.

\subsubsection{Multiclass Adaptive Boosting}
The boosting module implemented the multiclass SAMME algorithm~\cite{Zhu2009} through stochastic weighted resampling so that the ID3 base learner did not require a weighted-impurity interface. At round $r \in \{1, \dots, t\}$, $n$ training indices were drawn with replacement according to the current weight vector $\mathbf{w}_r$. The induced base tree $\pi_r$ was then evaluated across all $n$ rows of the original fitting population to compute the weighted training error $\epsilon_r$ via Equation~(\ref{eq:boost_err}).

Two numerical and termination rules were enforced during boosting:
\begin{enumerate}
    \item \textbf{Termination on zero or excessive error:} If $\epsilon_r = 0$ on the fitting population, boosting terminated immediately and retained $\pi_r$ alone with weight $\alpha_1 = 1.0$. Conversely, if $\epsilon_r \ge 1 - 1/k$, corresponding to $0.9$ for $k = 10$ classes, learner $\pi_r$ was rejected and boosting terminated, returning the previously accepted learners.
    \item \textbf{Log-space weight maintenance:} To prevent floating-point underflow in $\epsilon_r$ or overflow in $\exp(\alpha_r)$ across sequential rounds, instance weights were stored as normalised log-weights $\ell_{r,i} = \ln w_{r,i}$. Letting $W_r = \{i \in \{1, \dots, n\} \mid \pi_r(\mathbf{x}_i) \ne y_i\}$ denote the set of misclassified training indices at round $r$ and $\hat{\ell}_r = \max_{i \in W_r} \ell_{r,i}$, the log-error $\ln \epsilon_r$ was computed via the log-sum-exp identity as
    \begin{equation}
        \ln \epsilon_r = \hat{\ell}_r + \ln \sum_{i \in W_r} \exp(\ell_{r,i} - \hat{\ell}_r) - \ln \sum_{i=1}^n w_{r,i}.
        \label{eq:log_err}
    \end{equation}
    After computing $\alpha_r$ via Equation~(\ref{eq:samme_alpha}), misclassified log-weights were incremented by $\alpha_r$ and re-normalised in log-space.
\end{enumerate}

\subsection{Hybrid Class-Balanced Training Resampling}
\label{subsec:meth_balance}
The natural class distribution of the UNSW-NB15 growth pool is heavily skewed. The three most frequent categories, \emph{Normal} at $36.09\%$, \emph{Generic} at $22.85\%$, and \emph{Exploits} at $17.28\%$, account for $76.22\%$ of all growth records. Conversely, the four rarest categories, \emph{Worms} at $0.07\%$, \emph{Shellcode} at $0.59\%$, \emph{Backdoor} at $0.90\%$, and \emph{Analysis} at $1.04\%$, together constitute only $2.60\%$ of the pool. Training on natural proportions provides very few minority instances in subsamples, whereas pure equal-quota balancing at $10\%$ per class discards the majority of abundant-class records within a fixed draw budget $n$ and heavily duplicates rare records.

To control class-balancing strength continuously while keeping the total number of training draws fixed at $n$, a hybrid sampling proportion $\gamma_j$ was defined for each class $c_j$ across $j \in \{1, \dots, k\}$ using an interpolation weight $\lambda \in [0, 1]$ according to
\begin{equation}
    \gamma_j = (1 - \lambda)\beta_j + \frac{\lambda}{k},
    \label{eq:hybrid_balance}
\end{equation}
where $\beta_j$ denotes the natural proportion of class $c_j$ in the growth pool. Setting $\lambda = 0$ preserved the natural class proportions $\beta_j$, setting $\lambda = 1$ enforced uniform equal-class quotas $1/k = 0.10$, and setting $\lambda = 0.5$ averaged the natural distribution with a uniform prior according to $\gamma_j = 0.5\beta_j + 0.05$. Integer class draw quotas $n_j$ summing to $n$ were computed by taking $\lfloor n \gamma_j \rfloor$ and assigning remaining draws in descending order of fractional remainders.

Within each class $c_j$, sampling adapted to the available source count in the growth pool:
\begin{itemize}
    \item When the requested quota $n_j$ did not exceed the available class count in the source pool, $n_j$ records were drawn without replacement to maximise distinct flow coverage.
    \item When the requested quota $n_j$ exceeded the available class count in the source pool, $n_j$ records were drawn with replacement.
\end{itemize}
For a given random seed, the standalone decision tree and the SAMME boosting ensemble shared the same initial $\lambda$-balanced training sample of $n$ draws, and SAMME subsequently performed weighted resampling on that sample. For balanced bagging, however, bootstrapping a single pre-balanced sample would permanently exclude unsampled majority-class records across all $t$ members. Instead, each bagging member $r \in \{1, \dots, t\}$ drew a fresh, independent $\lambda$-balanced sample of $n$ draws directly from the full source growth pool using a deterministic member seed. Class balancing was applied exclusively to training samples; the pruning, validation, and generalisation partitions always retained their natural class proportions.
