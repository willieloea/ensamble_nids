\section{Background and Theoretical Foundations}
\label{sec:background}

Theoretical concepts underlying tree-based classification and ensemble aggregation are reviewed in Section~\ref{sec:background}. Subsection~\ref{subsec:bg_trees} defines top-down decision-tree induction and Shannon entropy. Subsection~\ref{subsec:bg_metrics} introduces alternative split criteria and binary threshold partitioning for ordered numerical attributes. Subsection~\ref{subsec:bg_pruning} contrasts pre-pruning and reduced-error post-pruning. Finally, Subsection~\ref{subsec:bg_ensembles} formulates bootstrap aggregation and multiclass adaptive boosting.

\subsection{Information-Based Decision Tree Learning}
\label{subsec:bg_trees}
Decision tree algorithms induce a hierarchical, rule-based classifier by recursively partitioning a labelled dataset $D = \{(\mathbf{x}_i, y_i)\}_{i=1}^n$, where $n$ denotes the number of instances~\cite{Kelleher2020,Quinlan1986}. Each instance $i \in \{1, \dots, n\}$ is described by a vector $\mathbf{x}_i = (x_{i,1}, \dots, x_{i,m})$ of $m$ descriptive attributes and belongs to one of $k$ mutually exclusive target classes in the class set $C = \{c_1, \dots, c_k\}$. Internal nodes in a decision tree represent tests on individual descriptive attributes, branches correspond to test outcomes, and terminal leaf nodes assign a target class label from $C$. Multiple tree structures fit the same training instances, so top-down tree induction applies a preference bias toward shorter trees with fewer test nodes by placing the most discriminative attribute tests near the root~\cite{Kelleher2020}.

In the standard ID3 algorithm introduced by Quinlan~\cite{Quinlan1986}, tree induction proceeds top-down by greedily selecting the descriptive attribute $b \in \{1, \dots, m\}$ that yields the greatest reduction in target class uncertainty. Uncertainty within a dataset $D$ is quantified using the entropy measure introduced by Shannon~\cite{Shannon1948}, defined as
\begin{equation}
    h(D) = - \sum_{j=1}^k \nu(D, c_j) \log_2 \nu(D, c_j),
    \label{eq:entropy}
\end{equation}
where $h(D)$ denotes the Shannon entropy of $D$ in bits, $j \in \{1, \dots, k\}$ indexes the target classes, and $\nu(D, c_j)$ denotes the empirical proportion of instances in $D$ with target label $y_i = c_j$, taking $0 \log_2 0 = 0$ by convention. A homogeneous dataset containing only a single target class has $h(D) = 0$, whereas a uniform class distribution over $k$ classes attains the maximum entropy of $\log_2 k$ bits.

When a categorical attribute $b$ with discrete domain $L_b$ partitions $D$ into disjoint subsets $D_l = \{(\mathbf{x}_i, y_i) \in D \mid x_{i,b} = l\}$ for each level $l \in L_b$, the expected remaining entropy $\xi(b, D)$ is the weighted sum of the subset entropies, given by
\begin{equation}
    \xi(b, D) = \sum_{l \in L_b} \frac{|D_l|}{|D|} h(D_l),
    \label{eq:rem}
\end{equation}
where $|D_l|$ and $|D|$ denote the cardinalities of subset $D_l$ and dataset $D$. The information gain $\iota(b, D)$ of partitioning $D$ on attribute $b$ is the resulting reduction in entropy, expressed as
\begin{equation}
    \iota(b, D) = h(D) - \xi(b, D).
    \label{eq:ig}
\end{equation}
Recursive partitioning terminates along a branch under three stopping conditions~\cite{Kelleher2020}. First, if all reaching instances share the same target label, a leaf node is created with that target label. Second, if no candidate attributes remain, a leaf node is created with the modal target class of the reaching instances. Third, if subset $D_l$ is empty, a leaf node is created with the modal target class of the parent partition $D$.

\subsection{Alternative Impurity Metrics and Continuous Splits}
\label{subsec:bg_metrics}
Quinlan~\cite{Quinlan1986} showed that information gain favours categorical attributes with large domains $L_b$, because a high-cardinality attribute fragments $D$ into numerous small, low-entropy subsets $D_l$ even when the attribute carries weak generalisation value. To penalise multi-way fragmentation, Quinlan~\cite{Quinlan1986,Quinlan1993} defined the gain ratio $\psi(b, D)$ by normalising information gain by the split information $\kappa(b, D)$ according to
\begin{equation}
\begin{aligned}
    \psi(b, D) &= \frac{\iota(b, D)}{\kappa(b, D)}, \\
    \kappa(b, D) &= - \sum_{l \in L_b} \frac{|D_l|}{|D|} \log_2 \frac{|D_l|}{|D|}.
\end{aligned}
\label{eq:gain_ratio}
\end{equation}
In the C4.5 system, Quinlan~\cite{Quinlan1993} combined Equation~(\ref{eq:gain_ratio}) with an eligibility constraint that restricted selection to candidate splits whose information gain $\iota(b, D)$ was at least the mean information gain across all tested splits at that node.

An alternative impurity criterion is the Gini impurity $\zeta(D)$. The quantity $\zeta(D)$ measures the probability of misclassifying a randomly selected instance from $D$ when labels are drawn according to the empirical class proportions $\nu(D, c_j)$~\cite{Kelleher2020}, defined as
\begin{equation}
\begin{aligned}
    \zeta(D) &= \sum_{j=1}^k \nu(D, c_j)\bigl(1 - \nu(D, c_j)\bigr) \\
    &= 1 - \sum_{j=1}^k \nu(D, c_j)^2.
\end{aligned}
\label{eq:gini}
\end{equation}
Substituting $\zeta(\cdot)$ for $h(\cdot)$ in Equations~(\ref{eq:rem}) and~(\ref{eq:ig}) yields the Gini impurity reduction.

To incorporate ordered numerical attributes into an ID3-style learner, multi-way categorical branching is replaced by binary threshold tests of the form $x_{i,b} < \theta$ versus $x_{i,b} \ge \theta$, partitioning $D$ into a left subset $D_1$ and a right subset $D_2$~\cite{Kelleher2020,Quinlan1993}. Sorting the distinct observed values $v_1 < v_2 < \dots < v_u$ of attribute $b$ restricts candidate thresholds $\theta$ to midpoints between adjacent values $v_\tau$ and $v_{\tau+1}$, where $\tau \in \{1, \dots, u-1\}$ and $u$ denotes the number of distinct values, whenever the associated target class labels differ between $v_\tau$ and $v_{\tau+1}$. The threshold $\theta$ that maximises impurity reduction between $D_1$ and $D_2$ is selected as the best split for attribute $b$. Unlike a categorical attribute removed after a multi-way split, a numerical attribute remains available to descendant nodes for further binary splitting at finer thresholds~\cite{Kelleher2020}.

\subsection{Overfitting and Tree Pruning}
\label{subsec:bg_pruning}
Unrestricted recursive partitioning continues until every leaf is homogeneous or all attributes are exhausted, causing deep subtrees to fit sampling noise and label conflicts in $D$~\cite{Kelleher2020}. As tree depth increases, leaf predictions rely on progressively smaller subsets of instances, increasing estimator variance on unseen data. Two structural regularisation families address tree overfitting:
\begin{itemize}
    \item \textbf{Pre-pruning:} Tree induction halts early when a stopping condition is reached, such as a maximum edge depth $d$ from the root or a minimum node cardinality. Pre-pruning reduces training computation directly, but introduces a horizon effect where locally weak splits that would enable informative descendant splits are prematurely blocked~\cite{Kelleher2020}.
    \item \textbf{Post-pruning:} The decision tree is first grown to full depth on the fitting dataset $D_f$ and then simplified bottom-up. In reduced-error pruning~\cite{Kelleher2020,Quinlan1993}, a separate pruning dataset $P$ is routed through the induced tree in a post-order traversal. At each internal node $v$, the unweighted count of classification errors $e_v$ committed by the existing subtree on the reaching pruning subset $P_v$ is compared against the error count $o_v$ committed if node $v$ were replaced by a single leaf predicting the modal class $y^*_v$ of the reaching fitting subset $D_v$. If $o_v \le e_v$, the subtree rooted at $v$ is replaced by the leaf $y^*_v$.
\end{itemize}
Because standard reduced-error pruning minimises unweighted classification error counts on $P$, the pruning criterion interacts with class imbalance: on skewed datasets, collapsing small minority-class subtrees reduces total errors on $P$ and increases overall accuracy while reducing minority-class recall.

\subsection{Ensemble Learning: Bagging and Multiclass Boosting}
\label{subsec:bg_ensembles}
Ensemble learning combines the predictions of $t$ base learners $\pi_1, \dots, \pi_t$ to improve generalisation relative to an individual base classifier~\cite{Kelleher2020}. The two principal homogeneous ensemble families for decision trees are bootstrap aggregation and adaptive boosting.

\subsubsection{Bootstrap Aggregation and Sub-Bagging}
Bootstrap aggregation, introduced by Breiman~\cite{Breiman1996} as bagging, trains $t$ independent base learners on resampled datasets $D_1, \dots, D_t$, where each $D_r$ for $r \in \{1, \dots, t\}$ is constructed by drawing $n = |D|$ instances uniformly with replacement from $D$. For classification, the ensemble prediction $\hat{\pi}(\mathbf{x}_i)$ aggregates hard class votes by uniform majority voting according to
\begin{equation}
    \hat{\pi}(\mathbf{x}_i) = \arg\max_{c_j \in C} \sum_{r=1}^t \delta\bigl(\pi_r(\mathbf{x}_i) = c_j\bigr),
    \label{eq:bagging_vote}
\end{equation}
where $\delta(\cdot)$ denotes the indicator function returning $1$ when the equality inside the argument holds and $0$ otherwise. Because each uniform bootstrap sample omits a fraction $(1 - 1/n)^n \approx \exp(-1) \approx 0.368$ of the instances in $D$, unstable learners such as unpruned decision trees induce diverse tree structures across the $t$ replicates. Breiman~\cite{Breiman1996} showed that aggregating unstable predictors across bootstrap replicates reduces prediction variance caused by sample perturbations, while leaving the functional form of each individual base tree unchanged. Sub-bagging instead draws proper subsets of size $\omega < n$ without replacement, increasing sample diversity across the $t$ learners while providing fewer training instances per tree. When bagging evaluates all $m$ attributes at every split rather than sampling random attribute subspaces, the ensemble remains standard bagging rather than a random forest.

\subsubsection{Multiclass Adaptive Boosting}
Whereas bagging trains high-capacity base learners in parallel, adaptive boosting sequentially trains weak base learners so that each round $r \in \{1, \dots, t\}$ emphasises training instances misclassified by earlier learners~\cite{Freund1997,Kelleher2020}. Each training instance $i \in \{1, \dots, n\}$ is assigned a non-negative weight $w_{r,i}$, initialised uniformly at $w_{1,i} = 1/n$. At round $r$, a base learner $\pi_r$ is induced using the weight vector $\mathbf{w}_r = (w_{r,1}, \dots, w_{r,n})$, either via weighted impurity calculations or by drawing $n$ instances with replacement according to $\mathbf{w}_r$, and is evaluated across all $n$ instances of $D$ to compute the weighted training error $\epsilon_r$ defined as
\begin{equation}
    \epsilon_r = \frac{\sum_{i=1}^n w_{r,i} \delta\bigl(\pi_r(\mathbf{x}_i) \ne y_i\bigr)}{\sum_{i=1}^n w_{r,i}}.
    \label{eq:boost_err}
\end{equation}
For binary classification with $k = 2$, Freund and Schapire~\cite{Freund1997} required $\epsilon_r < 1/2$ to assign a positive learner weight. In a $k$-class classification problem with $k > 2$, however, random guessing achieves an accuracy of $1/k$, making the binary condition $\epsilon_r < 1/2$ overly restrictive for shallow trees. Zhu \emph{et al.}~\cite{Zhu2009} proposed the SAMME algorithm to generalise adaptive boosting to $k$ classes by requiring only $\epsilon_r < 1 - 1/k$ and defining the learner voting weight $\alpha_r$ with learning rate $\eta > 0$ as
\begin{equation}
    \alpha_r = \eta \left( \ln \frac{1 - \epsilon_r}{\epsilon_r} + \ln(k - 1) \right).
    \label{eq:samme_alpha}
\end{equation}
Observation weights are updated for round $r + 1$ by multiplying the weights of misclassified instances by $\exp(\alpha_r)$ according to
\begin{equation}
    w_{r+1,i} = \frac{w_{r,i} \exp\bigl(\alpha_r \delta(\pi_r(\mathbf{x}_i) \ne y_i)\bigr)}{z_r},
    \label{eq:samme_update}
\end{equation}
where $z_r = \sum_{i=1}^n w_{r,i} \exp\bigl(\alpha_r \delta(\pi_r(\mathbf{x}_i) \ne y_i)\bigr)$ normalises the weight vector $\mathbf{w}_{r+1}$. The boosted ensemble predicts by confidence-weighted voting across the $t$ learners according to
\begin{equation}
    \hat{\pi}(\mathbf{x}_i) = \arg\max_{c_j \in C} \sum_{r=1}^t \alpha_r \delta\bigl(\pi_r(\mathbf{x}_i) = c_j\bigr).
    \label{eq:samme_vote}
\end{equation}
Zhu \emph{et al.}~\cite{Zhu2009} proved that Equations~(\ref{eq:samme_alpha})--(\ref{eq:samme_vote}) minimise a multiclass exponential loss via forward stagewise additive modelling and reduce to standard binary adaptive boosting when $k = 2$ and $\eta = 1$.
